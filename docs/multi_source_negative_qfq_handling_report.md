## 2. 指标行为矩阵(20 只负价股 + 20 只无负价股)

脚本:`tmp/gate_c_final/negative_price_indicators.py`;矩阵:`tmp/gate_c_final/negative_price_indicator_matrix.csv`。对每只股票全史计算 MA5/7/20/35(均线)、CROSS(MA7,MA35)(交叉)、涨跌幅(close/prev_close−1)、比例 DEV=(MA7−MA35)/MA35×100(除法)、log(close)(对数):

| 检查项 | 结果 |
|---|---|
| 指标计算崩溃 | 0(40/40 全部完成) |
| MA 在 warmup 后出现 NaN | 0 行 |
| DEV 除法 inf/NaN | **0 行**(20 只负价股全史 MA35 从未恰为 0;MA35<0 时 DEV 符号翻转——语义翻转行为按股记录在矩阵) |
| 涨跌幅 inf(prev_close==0) | 47 行(来源即 close==0 行;有零价除法暴露面,错误可定位到具体行) |
| log 未定义(close<=0) | 83,633 行(NaN 局部产生,量化了暴露面;本轮产品公式不含 LOG) |
| 负价区间产生交叉信号 | 20/20 只股均有(信号在负价上照常触发,未被阻止——行为已明确记录) |

结论:MA/交叉类良定义;除法类在负值域**符号语义翻转**但数值有限;零价(而非负价)才是 inf 的实际来源。均未发现会静默传播至组合结果的未处理 NaN(fast/full 引擎成交价均取 L2 raw,L1 值仅决定信号日)。
