## 2. 归因(按证据强度排序)

1. **复权模型差异(主因)**:A 为通达信仿射 a·p+b(锚随数据末日 20260724),B 为乘法 ratio(锚=cutoff 20260717)。两平面价格水平关系随时间回溯发散(既有对比:全史 2dp 仅 21.8% 一致)。MA7/MA35 交叉与 DEV≤2 回踩阈值对平面形状敏感,因此:
   - A 档仅-A 信号 82% 集中于 2012–2016(旧年代两平面最不同);
   - 仅-B 信号每年稳定 ~170–630 个(乘法平面在 DEV 阈值附近系统性多触发);
   - B 档(近端窗口)一致率升至 96.4%,与"近端 2026H1 两源 61% 2dp 一致"的既有梯度吻合。
2. **负前复权股票集中度**:仅-A 信号中 **94%**(1,443/1,537)、仅-B 信号中 49%(2,480/5,100)发生在有负价历史的股票上——分歧最大处正是仿射平面进入负值域的股票(负价年代窗口实测:A 567 信号 vs B 180,A 231 买 vs B 76 买)。
3. **数据覆盖差异**:B 集比 A 多 26 只(2026 年退市股,TDX 无数据);A 集早史更长(19901219 起 vs 20010427 起)且 B 有 49 只前导缺口截断。本轮实验统一使用共同池 ∩ 因子缓存(4,962/500),窗口内覆盖差异贡献很小(B 档仅-A 463 个)。
4. **公司行为(CA)邻域**:同一 fail_closed 政策双侧对称——A 档 A 拦截 676 笔;B 档 A/B 分别拦截 2,696/2,821 笔;full 引擎 clean30 双侧均以 unsupported_corporate_action 显式标注。差异来自信号日不同导致持仓窗不同,非政策不对称。
5. **锚点差异**:A 锚随最新数据日(20260724),B 锚=cutoff(20260717)。已知非错误(6 只停牌中公司行为的锚点恒等偏差在 B 集内已记录)。
