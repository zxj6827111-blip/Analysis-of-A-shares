## 4. 结论与使用建议

- 两套 L1 信号源**语义不同且都正确**:选"通达信原生前复权"= 与 TDX 客户端所见一致(含负价段);选"本地行情+Tushare因子前复权"= 乘法 QFQ 口径(恒正,与 Tushare/主流量化库一致)。
- 缓存与任务 hash 已按 signal_data_source/dataset_id 完全隔离,两源结果不会互串;同一策略在两源下的信号可能不同(比例类指标在负价段、事件窗附近差异最大)——这正是双源对照回测的研究价值。
- L2 执行(成交/涨跌停/滑点/估值)恒为 local_vendor raw,两源回测的**成交语义完全相同**。
