# 产品化补齐说明（方案「能测/有 API」→ 可用）

**日期：** 2026-07-22  
**分支：** `feature/astock-research-phase1`

针对此前「方案写了但只做到能测/有 API」的 **1～5** 项补齐如下。

---

## 1. 评价中心六视图（前端 + API）

| 视图 | 入口 |
|------|------|
| 总览 / 排名 / 热力图 / 卦象增益 / 年度·阶段 / 稳定区 | 实验中心 → **评价分析** `#btnExpEvaluate` → `#expEvalPanel` |
| 后端 | `POST /api/v1/research/evaluate`（`evaluate_trials`，含 regimes/yearly/cross_section） |

有 `symbol_metrics` 时评价结果附带 **板块横截面**（主板/创业板/科创板等，`infer_board`）。

---

## 2. 持续研究：真·可触发调度

| 能力 | 用法 |
|------|------|
| 文件型 Beat | `ScheduleBeatStore` + `due_schedules` / `fire_schedule` |
| 一次触发 | `python -m wtpy.apps.astock.research.beat_once --storage <storage_root> [--dry-run]` |
| API | `GET /api/v1/research/schedules/due`；`POST /api/v1/research/schedules/{name}/fire` |
| 行情更新后重排队 | `on_market_data_updated(platform, candidates)` |
| 漂移告警载荷 | `POST /api/v1/research/drift/monitor` / `monitor_drift_and_alert` |

说明：无需 Celery Beat；可挂系统计划任务每日调用 `beat_once`。单次 fire 上限 20 组以防误触。

---

## 3. 缓存 / 产物 / 基准（P3 产品说明）

| 开关 | 默认 |
|------|------|
| 实验 `engine` | `fast` |
| `artifact_level` | `summary`（meta/metrics；full 出明细） |
| `use_signal_cache` | `true`（信号/过滤/fast+summary 执行缓存） |
| 缓存目录 | `storage/astock/cache/{signals,filtered_signals,execution}/` |
| Parquet | 尝试写 `signals.parquet`；无 pyarrow 则 jsonl |
| 基准脚本 | `python scripts/bench_phase3_cache_fast.py` |

实验结束后默认 `promote_top_n=3` 自动 **full** 精复测。

---

## 4. 正确性文案（退出原因）

报告说明统一为：

- **time_exit**：持有期/时间止损  
- **weekday_exit**：指定星期平仓  
- **stop_loss / take_profit**：触发后下一可交易日开盘（既有规则）  
- 旧码 **hold_expired** → 归一为 **time_exit**

---
