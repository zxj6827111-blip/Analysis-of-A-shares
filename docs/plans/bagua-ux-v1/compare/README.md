## 交互状态断言（真实接口全链路）

1. **歧义消解**：输入 `000001` → 提示「000001 对应 2 个标的（平安银行·股票、上证指数·指数…），请在候选项中选择」+ 两个候选卡片，不代选。
2. **批量粘贴**：`600033,600064,000001` → 600033/600064 静默成功入列、000001 逐项提示歧义（不静默丢弃）。
3. **查询**：单票 600033 → 结果行含名称/周期/请求日期/实际行情区间/口径/主卦（地风升）/动爻（九二）；详情展开分层显示卦辞解读、操作信号、行情简判、OHLC、计算依据（含算法与数据集来源）。
4. **条件快照传递**：结果区「导出这 N 个标的」→ 导出面板 scope=picked、日期=查询日、来源「来自查询结果」。
5. **条件变更失效**：查询后改价格口径 → 「条件已变更，请重新查询。」结果区隐藏。
6. **真实筛选**：规则 735 + 范围（来自查询结果）+ 2026-09-11 → 命中 600033（与周五链复核 review_20260911.json 交叉一致）；零命中场景（20 日平台突破 × 000001）显示「零命中，不能从零命中导出」，无导出按钮。
7. **导出任务**：force_async 后台任务 → 记录行状态 queued→running→done，显示实际数据日；下载按钮出现。
8. **刷新恢复**：localStorage 记录活跃任务 id，刷新后继续轮询；服务端无记录时显示「任务记录已失效」。
9. **全市场导出（all_stocks=true + force_async=true）**：任务 `bqexp_83f654bc34e4` queued→running→done，进度消息「6986/6986（成功 6986 / 失败 0）」；产出 `meta / stock-all(5217) / etf-all(1769)` 三工作表，query_date=20260911，列结构与单票样本一致；样本见 `samples/export-all-market-20260911.xlsx`。
