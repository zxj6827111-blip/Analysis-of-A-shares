# PLAN-BAGUA-UX-V1.1-R1 整改记录（Codex 复核反馈）

复核结论（2026-09-12）：**部分完成，验收不通过**。本文件记录逐项整改与验证；未修改项如实标注。

## 追加需求（用户 2026-09-12）：查询结果的共识倾向颜色标注

**需求**：卦象结果与导出 Excel 一致，卦象与高岛「都好／都差／分歧」用明显不同颜色标出。
**用户反馈迭代**：初版判定不了就留空，导致多数票看不到颜色（如东方盛虹周线：
新开仓 × 高岛「一时难以脱售」，高岛词表未命中→空）。改为**每行都有颜色反馈**：

- ▲双好=红（#c00000/浅红底，与 Excel COLOR_GOOD_FONT 同值）、▼双差=绿
  （#0f7b0f/浅绿底）、分歧=琥珀、**其余一律显示中性「一般」徽章**（深色底灰蓝字）。
- 详情新增「共识依据：卦象立场 X × 高岛立场 Y」行（好=红、差=绿、中/不明=灰），
  让分歧/一般的成因透明——如东方盛虹「卦象中 × 高岛好」。
- **紧凑行（未展开）同步展示高岛断语摘要**：高岛作为独立条目紧跟主卦行，
  「主卦」「高岛」分类名加粗区分内容；摘要截断 60 字，全文仍在「查看详情」；
  共识徽章单独一行（结论属于两方共识，不挂在单方下）——用户反馈第三迭代。
- 后端 summary 新增 `consensus`、`gua_side`、`gaodao_side` 三字段
  （`_build_query_summary` 统一构建，复用 bagua/consensus 同源函数；高岛断语单次解析复用）。
- **筛选规则目录与规则中心同步**（用户反馈）：`/screen/rules` 改为「规则中心当前可见
  ∪ DEFAULT_REVIEW_RULES 预置复核规则」——规则中心删除（系统规则进 hidden 名单 /
  user 硬删）或归档的规则不再出现；735/5日外被 hidden 遮蔽但为周五链/导出依赖，
  强制纳入并保留 ⓘ 标志。前端去掉规则列表的加载缓存（每次进入筛选/导出页签重新
  拉取），已删除规则的勾选项自动剔除。
- 顺带修复：conftest 公式 fixture 路径错误（parents[1]→parents[2]）——本机真实
  指标/ 掩盖了它，原路径下 CI 的 fixture 兜底实际不生效，13 个公式测试在 CI 仍会
  跳过；修复后 CI 可真正跑通。
- 导出 Excel 的「倾向」列口径未动（仍只在一致时标注），页面比 Excel 多出中性态展示。

**验证**（真实数据 20260911）：华夏银行=分歧（琥珀）、民生银行=▲双好（红）、
宝钢股份=▼双差（绿）、东方盛虹=一般（中性）——四态截图 `compare/consensus-four-states.png`；
紧凑行高岛摘要实测（大族激光周线：主卦/高岛加粗、高岛紧跟主卦、徽章独立行，
`compare/consensus-bold-labels.png`）；
规则同步实测：/screen/rules 10 条，hidden 名单的量比增强/研究去MIN60 等已消失，
txt_735金叉及趋势（DEFAULT 强制纳入，hidden ⓘ）与规则中心可见规则齐全；
computed style 与 Excel ARGB 同值；详情共识依据行实测（持有「一般」：卦象中 × 高岛好）。
workbench 23 例 + 全量回归见会话记录。备注：高岛语气词表保守（如「后必大亨」「一时
难以脱售」未收录），扩充词表会同时改变导出 Excel 倾向列，留待用户决策；数据面 overlay
版本在长驻服务与本地进程间可能解析到不同 seq 导致同票卦不同——既有现象，与本功能无关。

## 二、正确性修复

| 复核问题 | 根因 | 整改 | 验证 |
|---|---|---|---|
| 指定周/月 400 | `2026-W36`→`2026W36`、`2026-08`→`202608` 直接提交 | 新增 `wbIsoWeekToSunday`/`wbMonthToLastDay`：ISO 周→该周周日、月→该月末历日（传周期末而非周期初，避免非交易日周期头回退到上一周期；后端按 asof 所在周期聚合） | 浏览器实测：W36→2026-08-31→周线查询成功（未收官标注）；2026-08→20260831→月线查询成功且月卦落在 8 月（风泽中孚·六四） |
| 混合查询改口径 | 整体用一个 adjust 提交 | 拆分两个 batch/query：股票组用用户口径、指数/ETF 组强制 raw；结果逐项显示各自实际口径（响应内 adjust） | 浏览器实测：600033 显示「Tushare 前复权」、510300 显示「未复权」同屏 |
| 搜索丢勾选 | 勾选状态从 DOM 读取，过滤后 DOM 失去选中项 | `wbs.checkedIds`（Set）独立保存；渲染从 Set 恢复；空结果提示「已选 N 条仍在生效」 | 浏览器实测：勾 735→搜索「5日外」→chip 持续可见→勾 5日外→清空搜索→两条均在勾选状态 |
| 结果与条件错配 | 响应返回后无条件写快照 | 提交时打 `reqToken`，条件变更即递增；响应回来 token 不匹配直接丢弃；快照内容取提交时固定值 | 代码审查 + 断言（快照构造自 conditions 常量） |
| 筛选跳转不带日期口径 | 跳转仅设置标的 | 「查卦象」跳转设置 period=DAY、timeMode=custom、custom=筛选日期、price=tushare_qfq（筛选口径）并提示 | 浏览器实测：跳转后 summary「日线 · 2026-09-11 · Tushare 前复权」 |
| 指定范围扩大为全市场 | `submit_screen_job` 预归一把 ETF-only 变空列表；`run_screen` 的 `if codes:` 把空列表当 None | `run_screen` 改 `codes is not None` 判空：归一后为空（含空列表）抛 `ScreenError`；混合范围返回 `excluded_count/excluded_note`，前端统计条下显示 | 单测 2 例（ETF-only 拒绝且不触达 run_weekly_review、混合范围 excluded=1）+ 浏览器实测 ETF-only 提交显示「筛选失败：指定范围内没有可筛选的 A 股股票」 |
| 筛选 error 显示「筛选中」 | `wbRenderScreenJob` 先判 `!== "done"`，error 落入运行分支 | error 分支提前独立判定（失败原因 + 建议日期） | 浏览器实测：error 状态正确显示「筛选失败」面板 |
| 导出断连误判失效 | 列表请求失败时 jobs=[] → 全部标记失效并停轮询 | `wbExportJobsCache` 保留上次列表；请求失败显示「暂时断连…稍后自动重试」并 5s 继续轮询；失效判定仅在成功拿到列表后进行 | 代码审查（断连路径不再清列表/停轮询） |
| 统计单位混用 | `evaluated = universe - missing - error_count`（规则×票次数） | 改为 `universe - missing - len(failed_codes)`（按票去重） | 单测通过（含失败票场景） |
