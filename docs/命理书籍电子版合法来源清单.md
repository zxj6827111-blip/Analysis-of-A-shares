**清单版本：** V1.0

**适用项目：** `wtpy-master / wtpy.apps.astock`  
**机器可读清单：** `docs/命理知识库书目来源清单.json`  
**下载工具：** `tools/download_metaphysics_corpus.py`

---

## 1. 结论

正式知识库不能把“大模型记得这些书”当作原始资料，原因是：

1. 模型训练语料和具体版本不可追溯；
2. 无法保证卷次、原文、异体字、页码和注本完整准确；
3. 模型可能混合不同版本、注本和后人解释；
4. 无法为规则提供稳定的文件哈希和页码证据；
5. 对现代版权书籍，模型不能替代正版文件，也不能重构并输出整本内容。

大模型可以协助 OCR 校对、概念抽取、规则草案、冲突对照、摘要和检索，但所有正式规则必须回到真实书籍段落复核。

因此推荐：

> 公版古籍下载并冻结原始文件；现代版权书由用户购买、借阅或提供自有合法副本；大模型只作为整理工具，不作为书籍来源。

## 3. 禁止进入正式语料库的来源

- 网盘群、论坛附件、BT、磁力链；
- 去除出版社水印的现代扫描本；
- 无版权页、无版本信息、无页码的拼接文本；
- 大模型凭记忆生成的“全书原文”；
- 把现代译注、点校或注释冒充古籍公版原文；
- 绕过 Internet Archive 受控借阅限制取得的文件。

## 4. 本地存储和下载

默认存储位置：

```text
<storage_root>/metaphysics/
├── corpus/
│   └── originals/
│       └── <source_id>/
└── manifests/
    └── download_receipt.json
```

预览下载：

```powershell
python tools/download_metaphysics_corpus.py `
  --manifest "docs/命理知识库书目来源清单.json" `
  --storage "storage/astock" `
  --dry-run
```

下载全部允许自动采集的资料：

```powershell
python tools/download_metaphysics_corpus.py `
  --manifest "docs/命理知识库书目来源清单.json" `
  --storage "storage/astock"
```

只下载指定书目：

```powershell
python tools/download_metaphysics_corpus.py `
  --manifest "docs/命理知识库书目来源清单.json" `
  --storage "storage/astock" `
  --source "ditiansui_jiyiao_1936_scan"
```

下载工具会：

1. 跳过现代版权或未授权资料；
2. 从 Wikimedia Commons API 动态解析原始文件地址；
3. 校验 Commons 文件远端 SHA-1 和文件大小；
4. 对所有本地文件计算 SHA-256；
5. 使用临时文件下载，校验后再原子替换；
6. 生成 `download_receipt.json`。

## 5. 进入知识库前的处理顺序

```text
下载合法原件
→ 冻结文件和哈希
→ 登记书目与版本
→ OCR或文本提取
→ 页码对齐
→ 人工/双模型校对
→ 段落切分
→ 概念与判断抽取
→ 规则草案
→ 人工审核
→ 回测和样本外验证
```

最低验收要求：

- 每本书有唯一 `source_id` 和 `edition_id`；
- 每个原文件有 SHA-256；
- 每段文本能回到文件、卷次和页码；
- 原文、现代标点、译文、注释分字段保存；
- 每条量化规则绑定真实段落证据；
- 邵伟华等现代资料在授权状态未确认前不得进入自动下载流程。
