查询卦象

支持单股 / 多股查询；可一键导出全市场日线、周线、月线卦象（通达信前复权 / Tushare前复权 / 未复权）。

操作说明

① 输入代码

股票：600000 / sh600000 / 600000.SH
指数：sh000001 / 000001 / 沪深300
ETF：sh510300 / sz159915 / 159915
多股：用逗号 / 分号 / 空格分隔（如 600000,000001,300750）

② 选周期与日期

先选「按日 / 按周 / 按月」，再选对应日期：按日选具体日期，按周选周，按月选月。默认按日、今天。也可用「指数」「ETF」预设下拉快速填入。

③ 选复权口径

股票可选：未复权 / 通达信前复权 / Tushare前复权。
指数与 ETF 无复权概念，系统自动按未复权(raw)计算。

④ 查询与导出

点「查询卦象」查看结果。查询指数 / ETF 后结果下方会出现「查看成分股卦象」按钮，可一键批量计算成分股卦象。查询股票后结果下方会出现「查看同卦股票」（全市场主卦+动爻相同，384态）与「查看同日柱」（静态日柱表）按钮。「导出查询股票」导出输入框内代码的日 / 周 / 月卦象 Excel；「全市场导出」为后台任务，导出全部股票（耗时较长，请耐心等待）。

卦象查询

代码支持 600000、sh600000、000001、指数 sh000001/沪深300、ETF sh510300/159915；多股：600000,000001,300750。先选周期，再选日期 / 周 / 月。

指数/ETF 无复权口径，卦象按未复权(raw)计算；下拉预设可快速填入（也可手动输入 sh000001、sh510300、sz159915 等）。导出为周报格式单表：code/name/week_end/OHLC/日柱/月卦组合/爻辞/周线组合/爻辞。日柱自动读桌面「股票+卦象/日柱(1).xlsx」。Ctrl+F5 强刷后生效。
四步使用指南
  1. 选标的：输入股票代码（600000）、指数（sh000001 / 000001 / 沪深300）或 ETF（sh510300 / 159915）；也可用「指数」「ETF」预设下拉一键填入。
  2. 选周期与日期：先选「按日 / 按周 / 按月」，再选对应日期；按日选日期，按周选周，按月选月。
  3. 选复权口径：股票可选未复权 / 通达信前复权 / Tushare前复权；指数与 ETF 无复权概念，自动按未复权计算。
  4. 查询与成分股：点「查询卦象」查看结果；查询指数 / ETF 后结果下方会出现「查看成分股卦象」按钮，可一键批量计算成分股卦象。查询股票后会出现「查看同卦股票」（全市场 384 态主卦+动爻相同）与「查看同日柱」按钮。
批量查询：用逗号 / 分号分隔多只股票代码。「全市场导出」为后台任务，「导出查询股票」按输入框内代码导出。
